# Moda Fácil

Site criado no Micronuage.

## Como rodar

```bash
npm install
npm run dev
```

- `npm run build` — gera a versão de produção
- `npm test` — roda os testes

Feito com: React, Vite, TypeScript, Tailwind CSS, React Router.

## Pedido original

O que foi pedido quando o site foi criado na Micronuage:

> Crie um sistema para controle de estoque de uma loja de roupas chamada "Moda Fácil". Deve ter login, cadastro de produtos (nome, categoria, quantidade e preço) e uma lista com busca. Visual limpo.
